# moodle-mbz-finder

Moodle のバックアップファイル（`.mbz`）を Moodle 本体へリストアせずに、ブラウザだけで
中身を確認し、必要な教材・提出物・ログ等を取り出すためのビューア（Finder）です。

`.mbz` はサーバーへアップロードされず、すべての処理はブラウザ内（Web Worker）で行われます。

仕様書: [`docs/moodle-mbz-viewer-spec.md`](docs/moodle-mbz-viewer-spec.md)（本プロジェクトでは
名称を `moodle-mbz-viewer` から `moodle-mbz-finder` に変更しています）。

## 開発

Node.js `^20.19.0` または `>=22.12.0` が必要です（Vite 8 の要件。それより古い Node では
`node:util` の `styleText` が無く起動時に落ちます）。nvm 等で切り替えてください。

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run lint     # oxlint
```

`DecompressionStream`（gzip）を使用するため、最新の Chrome / Edge / Firefox / Safari
での動作を前提としています。

## 実装状況

仕様書の「13. 実装優先順位」に沿って実装しています。

### Phase 1（実装済み）
- `.mbz` 選択（ドラッグ＆ドロップ / ファイル選択）
- gzip + tar のストリーミング展開（ファイル全体を一括でメモリへ展開しない）
- `moodle_backup.xml` / `files.xml` / 各 `section.xml` / 各 `inforef.xml` の解析
- コース名・バックアップ日時・Moodle バージョン・ユーザー情報／ログ有無・
  部分バックアップ判定などの概要表示
- コースインデックス風の折りたたみ可能なコース構造表示（セクション → 活動、
  チェックボックスによる複数選択）

### Phase 2（実装済み）
- 選択したリソースの取り出し（単一ファイルはそのままダウンロード、複数選択時は
  ZIP に格納してダウンロード）
- 大容量ファイルを想定し、抽出時も対象ファイルだけをストリーミングで読み出す
  （2 回目のアーカイブ走査で、必要なエントリ以外はメモリに保持せずスキップ）

### キャッシュ（section 10 相当・実装済み）
- 解析結果を IndexedDB に保存し、同じファイル（ファイル名・サイズ・更新日時が
  一致）を再度開いた際は解析をスキップして即座に表示します。

### Phase 3〜6（未実装・UI 上はロードマップ表示のみ）
- 提出物モードでは提出データを持ちうる活動（assign, quiz, forum, workshop 等）を
  ハイライト表示するところまで実装済みですが、件数集計・Excel エクスポート・
  Moodle 互換形式でのエクスポートは未実装です。
- ログモードはバックアップ内のログ有無の検出のみで、日別／週別集計や CSV
  エクスポートは未実装です。
- 小テスト（Quiz）専用表示、選択範囲だけを含む `.mbz` 再構成、Flexible Sections
  の階層表示は未実装です（バックアップに階層情報が保持されているか未確認のため、
  仕様書の方針どおり、確実に判定できるフラットなセクション構造のみを表示します）。

## 既知の制約

- ファイル抽出は、対象ファイルを ZIP としてブラウザのメモリ上に組み立ててから
  ダウンロードします。バックアップ全体ではなく選択した一部のみが対象になるため
  通常は問題になりませんが、選択範囲が非常に大きい場合はメモリを消費します。
- ファイル抽出は毎回アーカイブ全体を再走査します（gzip 圧縮ストリームの途中から
  読み出すシーク手段がないため）。数十 GB 級のファイルでは抽出のたびに時間が
  かかります。
- ファイルプールのディレクトリ構成（`files/<hash先頭2文字>/<hash>` 等）は
  アーカイブ内の実エントリ名から動的に解決しており、特定のディレクトリ階層を
  仮定していません。
