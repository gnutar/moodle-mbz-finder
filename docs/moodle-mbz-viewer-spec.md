# Moodle MBZ Viewer 仕様書（暫定版）

作成日: 2026-09-19

## 1. 目的

Moodle のバックアップファイル（`.mbz`）を Moodle 本体へリストアしなくても、
ブラウザ上で内容を確認し、必要な教材・提出物・ログ等を取り出せるビューアを作成する。

主な利用場面は以下。

- 過年度コースのバックアップ内容を確認する
- 教材・リソース・活動を再利用する
- 学生の提出物をまとめて取り出す
- バックアップ内のログを期間・活動単位で抽出する
- Moodle 本体では取り出しにくいデータを救出・整理する

## 2. 基本方針

- サーバーへ `.mbz` をアップロードせず、原則としてブラウザ内で処理する
- OS に依存しない Web アプリとして提供する
- 大容量 `.mbz` を想定し、ファイル全体を一括でメモリへ展開しない
- 必要な XML / ファイルを逐次・ストリーミング的に処理する
- 画面の中心は「Moodle のコース構造」とし、コンテンツ・提出物・ログを同じ構造上で扱う
- Moodle 4.5 のバックアップ／リストア仕様およびソースコードを参照して実装する

## 3. 初期画面・コース構造表示

`.mbz` を指定して開くと、以下を表示する。

- コース名
- バックアップ日時等の基本情報
- 含まれているデータ種別
  - ユーザー情報の有無
  - ログの有無
  - 一部セクションのみか
  - 提出物の有無
- コース構造

コース構造は Moodle の「コースインデックス」に近い UI とする。

- セクションを折りたたみ可能なリストで表示
- 各セクション配下にリソース／活動を表示
- チェックボックス等で複数選択可能

### Flexible Sections への対応

広島大学では Flexible Sections プラグインを利用しているため、
複数階層のセクション構造が存在する。

バックアップ内に階層情報が保持されているかは要確認。
保持されていない場合は、推測で階層を再現せず、
バックアップから確実に判定できる構造だけを表示する。

## 4. コンテンツ機能

### 4.1 選択

コース構造上で以下を選択可能とする。

- セクション単位
- リソース単位
- 活動単位
- 複数選択

### 4.2 取り出し方法

2種類を用意する。

#### A. 人間が直接利用できる形式

通常ファイルはそのまま取り出す。

例:

- PDF
- PowerPoint
- Word
- 画像
- 動画
- HTML 等

#### B. Moodle 再利用形式

選択したセクション／活動のみを含む `.mbz` を再構成し、
現在稼働している Moodle にリストアできる形式で出力する。

この機能は Moodle 4.5 の backup / restore 実装を確認して実現可能性を検証する。

## 5. 小テスト（Quiz）の扱い

小テストは問題バンクや問題タイプ等との依存関係が複雑なため、
通常のリソースとは別扱いとする。

### Moodle 再利用形式

可能であれば、関連問題を含めた `.mbz` として出力する。

### 人間可読形式

初期実装では HTML 等で以下を表示・出力する。

- 小テスト名
- 問題一覧
- 問題文

将来的には必要に応じて以下を追加する。

- 配点
- 選択肢
- 正答
- フィードバック

ランダム問題や特殊問題タイプへの対応は後続検討とする。

## 6. 提出物機能

「提出物」モードを選択すると、
提出データを持つ活動をコース構造上でハイライト表示する。

対象例:

- 課題（Assignment）
- 小テスト（Quiz）
- フォーラム（Forum）
- ワークショップ（Workshop）
- その他、ユーザー生成データを持つ活動

各活動について、可能な範囲で以下を表示する。

- 提出／投稿件数
- 添付ファイル数
- 合計容量（概算）
- 対象ユーザー数

複数活動を選択して一括エクスポート可能とする。

## 7. 提出物のエクスポート形式

### 7.1 Viewer 整理形式

標準形式として、ZIP 内に以下を格納する。

- Excel ブック
- 提出ファイル一式
- 必要に応じて補助 CSV

Excel は活動ごとにワークシートを分ける。

例:

- 課題A
- 小テストB
- フォーラムC
- ワークショップD

共通列の例:

- userid
- 氏名
- 学籍番号等の識別情報
- 提出日時
- 更新日時
- 評価
- 状態
- 添付ファイル
- コメント

活動固有情報は追加列として保持する。

添付ファイルは Excel と同じ ZIP 内に配置し、
Excel から相対リンクで開けるようにする。

### 7.2 Moodle 互換形式

可能な活動については、
Moodle 本体の「提出物をダウンロード」等で得られる形式に近い形式も提供する。

Viewer 独自形式と Moodle 互換形式の双方を選択可能とする方向で検討する。

## 8. ログ機能

「ログ」モードではコース構造を維持したまま、
ログ抽出条件を指定できるようにする。

### 8.1 ログ概要

バックアップ内のログについて以下を表示する。

- 最古のログ日時
- 最新のログ日時
- 総ログ件数
- 日別または週別ログ件数グラフ

期間未指定時は全期間を対象とする。

### 8.2 絞り込み

以下の条件を組み合わせて抽出可能とする。

- 開始日時
- 終了日時
- セクション
- 活動／リソース

セクションを選択した場合は配下の活動を対象に含める。

### 8.3 出力形式

大規模データを考慮し、CSV を基本形式とする。

必要に応じて複数 CSV や ZIP に分割する。

## 9. 大容量ファイルへの対応

数GB〜数十GB級の `.mbz` も想定する。

### 基本原則

- `.mbz` 全体をメモリへ展開しない
- XML やログを逐次処理する
- 解析中も UI 操作を妨げない
- Web Worker 等を利用してバックグラウンド解析する

### ログ解析

`.mbz` を開いた時点から、コンテンツ表示と並行してログ解析を開始する。

解析結果は段階的に UI へ反映する。

例:

1. ログ存在確認
2. 読み込み進捗
3. 日付範囲
4. 日別／週別件数
5. その他の統計

全ログ行を保持せず、日別件数等のカウンターだけを保持する方式を優先する。

## 10. 解析結果のキャッシュ

解析結果はブラウザの IndexedDB 等へ保存する。

次回、同じ `.mbz` を開いた際には、
保存済みの解析結果を再利用して高速表示できるようにする。

### ファイル識別

巨大ファイル全体のハッシュを毎回計算することは避ける。

候補:

- ファイル名
- ファイルサイズ
- 最終更新日時
- バックアップ内の course id
- バックアップ日時
- Moodle バージョン
- その他の軽量メタデータ

これらを組み合わせてキャッシュキーを生成する。

必要に応じて部分ハッシュ等を追加する。

## 11. ブラウザを閉じた場合

Web Worker 等の処理は原則としてページ／タブを閉じると終了する。

そのため、

- 解析途中の状態を IndexedDB に逐次保存
- 次回起動時に途中結果を再利用
- 可能であれば解析を再開

という設計を検討する。

## 12. UI の基本構成案

画面はおおむね以下の構成とする。

- 上部
  - コース名
  - バックアップ概要
  - コンテンツ / 提出物 / ログ モード切替
- 左側または中央
  - Moodle コース構造
- 右側または上部
  - 選択中モードの詳細情報
- 下部
  - 選択件数
  - 推定出力サイズ
  - エクスポートボタン
  - 解析進捗

## 13. 実装優先順位（暫定）

### Phase 1
- `.mbz` 選択
- アーカイブ構造読み取り
- Moodle バックアップメタデータ解析
- コース構造表示

### Phase 2
- 通常リソースの抽出
- ファイル単体／複数ダウンロード

### Phase 3
- 提出物解析
- Excel + 添付ファイル ZIP 出力

### Phase 4
- ログ解析
- 日別／週別分布
- 条件指定 CSV エクスポート

### Phase 5
- 選択したセクション／活動だけを含む `.mbz` 再構成
- Moodle へのリストア互換性検証

### Phase 6
- Quiz 等の複雑な活動への対応拡張
- Flexible Sections 等のプラグイン対応

## 14. 未確認事項

以下は Moodle 4.5 のソースコードおよび実際の `.mbz` サンプルで確認する。

- `.mbz` の実際の圧縮形式とブラウザでのストリーミング展開方法
- Moodle 4.5 における XML / files の対応関係
- 部分バックアップ `.mbz` の再構成条件
- Quiz と question bank の依存関係
- 各活動のユーザーデータ格納形式
- ログの格納形式と並び順
- Flexible Sections の階層情報がバックアップへ保持されるか
- Moodle 標準の各種エクスポート形式
- 数GB〜数十GB級ファイルに対するブラウザ実装上の制約
